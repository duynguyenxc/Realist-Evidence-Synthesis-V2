# How much did a two-catalogue search miss?

Generated by `scripts/catalogue_overlap.py`. No model was called; this cost nothing.

## The question

The registered protocol searched OpenAlex and Crossref and produced **1,863 records**. Reporting that number is required; knowing whether it is *enough* is not something the protocol can answer about itself. So the same registered vocabulary was run through four further catalogues and the results compared against the corpus, record by record.

**A record we did not have is not automatically a record we missed.** It may be the wrong literature. Every new record is therefore passed through the same theory-grounded dictionary used for the evidence map, and the figure that matters counts only those carrying **both** an intervention term and an achievement-emotion term — the minimum for a record to say anything about this review's question.

Two numbers, and the second is the one that matters.

**Almost nothing overlapped: 3 of 590 (1%).** That is not the reassuring result it first looks like — it says the catalogues are returning largely disjoint sets, which means the registered search is not a sample of the same pool seen from a different angle.

**But most of what they add is not this review's literature.** Of the 587 unseen records, only **67 carry both an intervention and an achievement-emotion term**; 220 carry one of the two and 300 carry neither. Against a corpus of 1,863, the genuine shortfall is **67 records, 3.6%** — small, and now a measurement rather than an assumption.

### Why the overlap is so low, checked rather than guessed

The first suspicion was the query itself: the DOAJ iterator originally asked for `sort=created_date:desc`, which returns the *newest* matches rather than the best ones — the same defect this project recorded for Crossref cursor paging on 2026-11-16, where the ranking is silently dropped. It was removed and DOAJ re-run on relevance. **The overlap did not move** (1 of 370 either way), so the sort was a real bug but not this cause. It is fixed regardless.

What remains is the registered search's own shape. It takes the top N hits per query by relevance from a catalogue that ranks largely by citation weight, so it is sampling the head of a distribution. DOAJ indexes only fully open-access journals, many of them small, regional or new — the tail. The two are not disagreeing about relevance; they are looking at different ends of the same literature. **That is a limitation of top-N retrieval, and it belongs in the manuscript's limitations whether or not a catalogue is added.**

## What each catalogue is actually worth here

**DOAJ is the one worth adding.** It indexes only fully open-access peer-reviewed journals, so its hits are in scope *and* obtainable as full text — which matters for a project where 694 of 1,266 open-access links yield no file. It is also the catalogue that had to be repaired before it would run at all: the command imported a module that was not in the repository, and once fixed it was discarding the DOI and abstract of every record it stored.

**arXiv is the one worth refusing, and now with a reason rather than a hunch.** The protocol excludes preprints, and the content confirms the exclusion is doing work: the returns are sentiment analysis, multimodal emotion recognition, affective computing and HCI — the literature this review's negative keywords exist to exclude.

**PubMed could not be asked.** NCBI answers HTTP 200 with an HTML block page, so a client reports zero results rather than a refusal. For a review of educational psychology this is the most costly of the four to lose, and the absence would have been invisible. `SOURCE_AUDIT.md` has the detail.

## What follows

Nothing here has been merged into the corpus. The protocol names the search, and changing it is an amendment for the supervisor, not a file copy. The recommendation that follows from the numbers is narrow: **add DOAJ, decline arXiv, and treat PubMed as a known gap** until a key or another route is available — and say so in the limitations rather than leaving a reader to assume the search covered it.
